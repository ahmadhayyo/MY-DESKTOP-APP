# Skill: Web Research → Document

## 1. Search, don't browse
- Use `web_search(query=...)` or `web_answer(query=...)`. Never open a browser to
  Google (it hits a CAPTCHA and fails). Run 2–4 focused queries.

## 2. Extract from the snippets
- Pull the concrete facts, figures, and quotes directly from the returned
  snippets. Note the source for each key claim.

## 3. Synthesize
- Organize into sections: intro, key points, details, conclusion. Write in the
  user's language. Do not copy long passages — summarize in your own words.

## 4. Deliver
- Write the result to the requested format (Word/Excel/Markdown) in the workspace
  or on the Desktop, formatted cleanly.

## 5. Report
- Summarize the findings and say where the file was saved.
